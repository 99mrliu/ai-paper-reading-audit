# 阅读判断：建议采用随机搜索作为第一版基线，搜索设定需适配

对当前“六个参数、每任务36次完整训练、重要参数未知、任务分布不同”的情况，建议先建立固定分布的独立随机搜索基线。理由是它简单、易记录，且不会像笛卡尔网格那样为不重要坐标的组合反复付出训练预算。**这是一项有条件的工程选择；论文没有验证我们的表格模型，也没有证明36次必胜或能找到全局最优。** 总体适配结论为“需改造”，实际收益仍“信息不足”（I1、I2、U1）。以下页码均指PDF页码。

## 方法与预算利用

先定义合法配置空间与抽样分布，独立抽取候选配置，逐一训练，在事先确定的验证集上计算同一指标，再选择验证表现最好的候选。抽样不随中间分数更新；测试集留作选择完成后的评价。固定种子、候选清单和训练随机性记录有助复核，但不意味着所有运行都确定无噪声（C1–C2）。独立试验也使增加、停止和并行执行试验较方便（PDF p.3、p.22）。

低有效维数指响应面主要随少数坐标变化，不等于输入特征维数低，也不意味着其他参数绝对无效。已查看图1及图注（PDF p.4）：横轴是重要参数，纵轴不重要；左边九点网格只投影成三个横坐标，右边九个随机点有九个不同横坐标。短原文为“With grid search, nine trials only test g(x) in three distinct places.” 这说明投影覆盖的机制，不是九次训练必然优于网格的实测结论；随机点仍可能聚集、留空洞（C3）。

应用到六参数时，完整规则网格的预算为各坐标档数的乘积；预算越紧，越难同时细化所有未知的重要坐标。随机搜索可让每次试验同时尝试新的连续坐标值。但离散参数会重复，强交互、很窄的优质区域或参数化不佳会削弱收益。不要为凑36次而假定每个参数能有相同档数，也不要提前把某一任务识别的重要参数固定为所有任务的重要参数。本文GP/ARD分析显示七维问题的有效维数约为1–4，且重要参数随数据集改变（PDF pp.14–15，C4–C5）；这是本文模型与空间内的拟合证据，不能证明我们的模型也如此。

DBN专家预算还在数据集间明显变化（13至102次，PDF p.19），后做的任务受益于前面任务经验（PDF p.20，C13–C14）。专家流程结合手工调参、多分辨率网格和坐标下降，已近似顺序自适应算法，不能把128对41次称为随机战胜/输给“纯网格”的公平单因素试验。旧实验没有使用相同测试评分加权方式，也是解释差异时的限制（C16）。即使64次以上随机搜索仍波动，表明优质配置区域可能很小（C17）。

**待解决的原文冲突：**摘要（PDF p.1）写“四个/七个相当、一个/七个更好”，图9和PDF p.21逐项结果却是八个数据集。本报告采用图注和逐项结果的八个口径，不静默修正摘要，也不猜原因（C18）。

## 搜索分布决定随机搜索在找什么

“随机”不能代替空间设计。本文实际混合分类选项、线性均匀、对数均匀、取整、启用概率和条件参数。例如学习率覆盖多个数量级，采用对数域抽样；是否使用预处理及保留多少PCA方差也改变候选概率（PDF pp.10–11、18–19，C10–C11）。同样边界、不同坐标变换或类别权重会产生不同概率质量；把正数参数在原值上均匀抽样和在对数域均匀抽样，效果不能视为相同。对数抽样需要正的合法范围，不能直接覆盖零值；零正则可作为单独概率质量。

在事先固定分布下，若“足够好”集合的概率质量为q，36次独立抽样至少命中一次的条件概率是 **1−(1−q)^36**（基于PDF p.16独立未命中乘积的推导，I2）。该式不是本任务的数值预测；q未知，不能拿论文模拟的1%目标体积替代。实际训练噪声也会影响验证排名与“足够好”的定义。扩大空间加入许多有害选择会降低q，故“覆盖更宽”不自动代表36次更好。

## 具体适配与后续信息

1. **可直接用：**固定分布独立采样、按验证指标选择、保存全部候选与结果的流程（C1–C2）。建议将36次额度首先作为一个事先规定的搜索实验，不凭中间结果静默调整分布后仍称其独立随机基线。
2. **需改造：**为六个真实参数明确类型、合法范围、线性/对数尺度、离散权重、条件依赖及无效组合处理。使用模型知识排除非法区域；不要照搬本文神经网络数值范围。当前连模型族和参数名称也未知，不能给出可信的inputs式配置（C8、C10、I1）。
3. **需改造：**按部署需求确定分类指标及数据划分，确认不平衡、分组、时间相关或分布偏移；预处理只在训练数据拟合。不同候选使用可比较的验证规则，测试集不用于调空间。本文图像任务的固定划分不自动适合表格数据（C16、C21）。
4. **信息不足：**明确36次是否包括重试、训练种子重复、最终重训或多折训练，及“一次完整训练”的资源定义。记录失败原因，避免只保留成功配置造成选择性报告；若每次训练成本差异大，未来同时记录次数和总计算成本（C22、U1）。
5. **需改造：**未来有额外实验预算时，在代表性表格任务上预先统一空间、评价、次数和资源口径，再与网格及选定自适应算法比较；跨任务记录胜负、收益、波动和失败，而不只挑最有利任务。重复搜索和方法对照本身需要另外训练预算，本次未执行（I1、U1）。

随机搜索是非自适应基线，后续自适应方法可根据已有结果调整候选；本文DBN专家实验提供了顺序策略可能更有效的证据，未来工作也明确推荐自适应方法。作者要求以随机搜索作为比较基线（PDF p.23：“consider random search … as a baseline for performance”），并没有证明它优于所有自适应算法。本文关于自适应基础设施难度的讨论属于当时环境，不能外推为现代工具包的事实（C14、C19）。

需要进一步确认的信息是：模型和六参数定义、合法范围与先验、数据量及标签结构、跨任务差异、目标指标、划分与泄漏风险、预算计费和训练随机性。若要复现论文，再补读其引用的Larochelle等2007原实验及当年代码、补充材料，核实DBN对照与摘要计数；这些来源本次没有取得。材料不足限制了性能判断，但不足以反推出随机搜索不适用。
