# 同作者、同能量显示值，也不能混用两篇论文

本次作者侧检索发现Strubell等另有AAAI2020扩展文章，题名为Energy and Policy Considerations for Modern Deep Learning Research，DOI10.1609/aaai.v34i09.7123，pp.13693–13696。它和主包的ACL2019文章是不同题名、会议和年份的作品，不当成同一PDF的新版本或已确认勘误。

本地提供source-excerpt.txt、原式(2)小片段、Table2表头与BERT行原截图。2020原PDF首页注明AAAI版权保留，未假定全文再分发许可，因此不把完整下载PDF放包；小片段限于本问题必需内容并署名。source-record.json保留官方来源、发布日期、原文件哈希、PDF页码、印刷页码和裁片坐标。关键数字与单位也以可读文本保存，不要求评审联网补齐证据。

2020 Method式(2)前后叙述由原0.954减半的更新能源结构假设；并没有提供当地设施实测因子。为核查关键因子变化，再保留一个7词原文短片段（PDF第2页/印刷13694，式(2)上方）：

> we cut this number in half

以下表格是作者侧按两篇原文事实整理，不是额外原文引文：

| 论文 | 方程位置 | 表格位置 | 电量显示kWh | 系数lb/kWh | 排放显示lb |
| --- | --- | --- | ---: | ---: | ---: |
| ACL2019 P19-1355 | PDF2/3646式(2) | PDF4/3648 Table3 | 1507 | 0.954 | 1438 |
| AAAI2020 7123 | PDF2/13694式(2) | PDF3/13695 Table2 | 1507 | 0.477 | 719 |

因此从1438到719不能推出硬件能耗减半，也不能把2019引用悄悄换成2020因子。“存在新假设/新估计”与“旧文笔误被正式勘正”是不同主张，后者需要独立勘误证据。更不能将0.477当作当前任意地区的因子。

原AI输入prompt.txt是在既有B对话追加的阅读问题，提供了2019当前PDF、2020有限片段和明确标注的作者概述。完整2020PDF未提供给模型，不声称它核验过全文。该追加不属于原冻结的A/B首答比较，不用于提高其通过项。实际输出、真实交付脚本、作者审查和重算分别保存；不能将作者的原文检索说成模型自己的联网检索。

复算作者条件模型，在包根运行：

```sh
python3 version-check/verify_versions.py
```

脚本用Fraction分别保留显示1507与由79.2小时得到的未舍入能量，在两个因子下计算精确值和half-up整数显示。输出与author-version-results.json比对。它不确定作者原始底稿、实际舍入位置、GPU功率来源或真实当地排放。

在玻尔尝试复做：继续原B对话，或新建同文献对话后提交prompt.txt；如用新对话，应记录上下文差异，不期待相同措辞。先保存原答，随后用原PDF和短片段核查每个引用的题名、表号、因子、假设与结论。没有2020全文时仅限给定片段判断；未完成验证如实保留。
