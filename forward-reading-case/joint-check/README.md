# 从“各自兼容”到“同一参数联合可行”

这是在90分案例基础上新增的确定性约束分析与新工具，针对真实可运行核算器的解释边界，不声称原论文有科学错误。

## 原有输出的边界

既有audit_energy.py把显示舍入当条件性区间，分别计算energy_check和carbon_check的重叠。两个结果是必要条件，工具没有给出联合可行结论。读者若把两个true写成“存在同一时长同时解释”，就把两次存在量词误合并：存在t使A成立、存在t使B成立，不蕴含存在同一t使A与B同时成立。

我们以[legacy_counterexample.py](legacy_counterexample.py)实际运行既有工具，[完整输入和输出](legacy-output.json)保留了两个true。例子明确是构造：合计1kW设施功率、1lb/kWh，所以E=t kWh、C=t lb；t以20小时步长显示为0，原工具包络为[0,10]。能量显示2±0.5要求t落在[1.5,2.5)，排放显示8±0.5要求落在[7.5,8.5)。各自与宽包络重叠，却没有共同t。粗步长只是让问题可见的合成条件，不是论文采样或测量误差。

## 技术方法与为何使用精确有理数

[paper-joint-rounding Skill](skill/SKILL.md)把所有显示约束反解到同一个非负参数轴。工具只支持y_i=rate_i×t、已知正系数、单位已归一化，输入十进制先转精确Fraction；舍入边界除以系数后以分数保存，避免二进制浮点把极近或恰相接的边界错误合并。它不处理多参数、非线性、零系数、单位自动识别或测量误差关联，超范围返回unsupported_or_invalid，而非“论文不兼容”。

half_up（非负数）将显示y对应为[y−q/2,y+q/2)，负下界截到0；half_even在y/q为偶数时两端都包括，为奇数时都不包括。每个输入须明示规则，y为q整数倍。交集取最大下界与最小上界；相等端点必须所有限制都包含该点，才有单点解。可行时返回经逐项确认的数学见证，不把它冒充原作者输入。

例如约束t显示2步长1、3t显示8步长1：half_up得到[1.5,2.5)与[2.5,17/6)，联合为空；half_even得到[1.5,2.5]与[2.5,17/6]，仅t=2.5可行。同样的显示值，规则会改变边界结论。原论文没有给出取整实现，不能由某规则下兼容反推作者实际用了该规则。

## 回到原论文，而不止构造边界

按PDF第2页式(1)/(2)及第4页BERT行，功率固定12041.51W、PUE1.58、因子0.954lb/kWh，单位归一化后能量率19.0255858kWh/h、排放率18.1504088532lb/h。表中79h若也按步长1显示，得到[78.5,79.5)，与能量1507和排放1438的反解区间相交，仍允许约79.199318–79.235405h。79.2与79.21均可，精确79不可。所有结论都在“系数固定、输出half_up、时长整数显示”的假设内，不证明测量、取整规则或内部计算。

因此“将显示79当精确输入算不回去”与“所有显示约束联合不兼容”不同。前者已验证失败，后者在此假设下不失败。新工具没有推翻原案例；它明确了哪些意义的兼容可以成立。
