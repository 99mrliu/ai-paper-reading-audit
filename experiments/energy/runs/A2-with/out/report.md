# Strubell 等（ACL 2019）能耗与碳排阅读审计

审计对象为随附 *Energy and Policy Considerations for Deep Learning in NLP*，作者 Emma Strubell、Ananya Ganesh、Andrew McCallum，ACL 2019，印刷页 3645–3650，共 6 个 PDF 页。以下页码均从 PDF 第 1 页起，并附印刷页。仅使用本地 PDF 与任务给定数据；未取得被引原论文、原始功率样本、训练日志或补充代码，也未联网核查。按随附 `skill/SKILL.md` 执行；来源摘要见 `source-sha256.txt`。

**引用判断：应撤回“一个Transformer模型产生626155公斤碳排”的原句。** 它同时混淆质量单位、单次训练与搜索预算，并将估计写成确定实测。PDF p1（3645）Table 1 表头为 “CO₂e (lbs)”，626,155 位于 Transformer 下的 “w/ neural arch. search”；p4（3648）Table 3 的 NAS GPU 行给出同一数，表注明确单位为 lbs。626,155 lb = **284,019.13 kg，约 284 公吨**；Table 1 的 Transformer big 单次训练估计则为 192 lb，约 87.09 kg。

建议引用为：“Strubell 等（2019，Table 1、3）在其 GPU 换算方案、PUE 1.58 和美国平均排放因子假设下，估计所分析的神经架构搜索预算对应约 626,155 lb（约 284 吨）CO₂e；这不是单次 Transformer 训练的直接碳排实测。” 此处沿用论文 CO₂e 标记，并不表示我们独立验证了其温室气体覆盖范围。

**1. 方法到底测了什么，又外推了什么**

PDF p2（3646）§2 的短引文 “Each model was trained for a maximum of 1 day” 限定了测量窗口。作者使用开箱默认配置训练，除 ELMo 使用 3 张 GTX 1080 Ti 外，其余使用单张 Titan X；GPU 功率由反复查询 `nvidia-smi` 取样并求均值，CPU 功率由 Intel RAPL 取得。公式另外列出 DRAM 功率，但正文没有给出其采样域、频率、完整原始记录或校准信息，不能把“写进公式”当成已经单独核实的测量证据。RAPL/设备遥测也不是设施电表。

作者随后使用原论文报告的完整训练时长和硬件估计训练至完成的成本（p2 右栏：“using training times and hardware reported in the original papers”）。故表内多日、多卡结果不是作者在对应设备上完整训练并用设施电表积分得到。尤其本地采样 Titan X/1080 Ti 与 Table 3 的 P100/V100 不一致；ELMo 正文原训练设备还写作 GTX 1080，而表内写 P100×3（p3 §2.1、p4 Table 3）。本文没有充分交代这些硬件之间如何转换功率、吞吐或 CPU/DRAM 配置，不能替它补上换算依据。

按 p2 式（1）、（2），把易混的符号改写为有明确单位的量：

\[
P_{IT}=p_c+p_r+g p_g\quad[W],\qquad
E_{facility}=\frac{P_{IT}}{1000}\,t_{h}\times1.58\quad[kWh],
\]
\[
C_{lb}=E_{facility}\times0.954\ [lb/kWh],\qquad
C_{kg}=C_{lb}\times0.45359237.
\]

其中 CPU 和 DRAM 分别是所有插槽的平均功率，GPU 项才是单卡平均功率乘卡数。1.58 是论文采用的 **2018 年数据中心全球平均 PUE**，不是本次训练机房实测；0.954 lb/kWh 是论文引 EPA 2018 的美国平均因子，约 **0.432725121 kg/kWh**，不是任意地区、任意年份都可直接使用的常数。p2–3 以美国与 AWS 电源结构近似说明其合理性，这仍是外推理由，不能验证某一云区域或本地训练的真实排放。

原文把含时间的式（1）结果称为 “total power”，其他段落也有把 kilowatts 称作能量的用语。按公式、时长和 Table 3 “kWh·PUE” 列理解，它计算的是能耗；不能仅凭名词不严谨宣判公式量纲错误。除以 1000 是 W→kW，时长须用小时。表内功率在本次复算中解释为 **CPU+DRAM+所有 GPU 的合计 IT 功率**，不再乘硬件列卡数；这是与公式及表值相符的口径，不是对原始传感器数据的独立证明。PUE 只乘一次，表内能耗已包含它。

**2. Table 3 五个有功率行的逐项复算**

来源：p4（3648）Table 3，已对照该页渲染图核对表头、设备和跨行位置。下表固定使用论文系数 1.58 和 0.954；Δ均为“复算−印刷值”。能耗是含 PUE 的 kWh，排放为 lb。计算保留未舍入中间值。

|T2T base，P100×8|1415.78 × 12|26.8431888 / 27|−0.1568112|25.6084021 / 26|−0.3915979|

例如 T2T big：1.51543 kW × 84 h = 127.29612 kWh（IT），再乘 1.58 得 201.1278696 kWh，乘 0.954 得 191.8759876 lb。NAS 使用相同功率，但时间是完整搜索的换算预算，不能把它视作 big 的一次训练。

除 BERT 外，四行的名义能耗和排放分别按最近整数舍入即可得到印刷值。**BERT 用表内 79 h 不满足这个检查**，仅把最终结果舍入不能解释差异。不过 p3（3647）§2.1 明确写 NVIDIA 方案为 3.3 天，即 **79.2 h**：

12041.51 / 1000 × 79.2 × 1.58 = **1506.82639536 kWh**；乘 0.954 = **1437.51238117 lb**，分别舍入为 1507 和 1438。正文存在直接支持的时长候选，因此“表内小时显示较粗、计算保留 79.2 h”是有证据的解释；未取得工作表，仍不能断言作者实际上用了哪一列隐藏精度，也不应武断认定作者算错或已被证明无误。

另做了两套显式条件检查：`round_display` 假设功率按 0.01 W、时长按 1 h、印刷能耗和排放按各自单位的 1 四舍五入，固定 PUE 和因子；`round_all` 在此基础上另假设 PUE 按 0.01、因子按 0.001 lb/kWh 舍入。五行在两套假设下，能量与排放的各自区间均与印刷区间重叠。BERT 第一套的能耗范围为 1493.50786515–1512.53469915 kWh，故包含印刷 1507 的舍入范围。这里的一小时假设是敏感性分析，**不是已知的原始精度**；重叠仅表示未被相应假设排除，既非测量误差条、置信区间，也不证明科学意义或物理模型正确。能量、排放分别的重叠检查也不自动证明存在同一组隐变量同时重现二者；BERT 的 79.2 h 候选则实际重现了两项整数结果。

Table 3 三个 TPU 行（BERT、NAS、GPT-2）缺功率，表注说明 “lack of public information on power draw”。它们的能耗和碳排为未知，不能填零，也不能从美元云价反推。云价反映设备、计费和抢占/按需选择；p3 脚注 7 给出价格范围，其上下界不是碳排置信区间。论文的 TPU 成本优势讨论不能直接变成 TPU 碳排优势结论。

**3. Table 1、3、4 是不同预算，不能互换**

Table 1（p1，3645）是压缩展示：NLP pipeline 单次训练 39 lb、加调参和实验 78,468 lb；Transformer big 192 lb、加架构搜索 626,155 lb。它们是特定研究预算的估计，不能推成所有 NLP 模型的普遍倍数。表内旅行、年人均与汽车终生的比较还具有不同时间范围和核算边界；只能作为所列估计的量级参照。

NAS 的时间来源在 p3 §2.1：979M 搜索训练步，按单 TPUv2 核 300k 步用 10 h 换算约 32,623 TPU h，再报告等效 8×P100 方案 274,120 h。其 GPU 行同时依赖跨硬件速度换算和功率估计；不是对实际 TPU 搜索排放的直接测量。274,120 h 应与整组 8 卡功率配对，等效累计 GPU 小时为 2,192,960；不能把累计单卡小时再与整组功率相乘。正文没有充分给出该跨硬件换算的可复现实验细节。

Table 4（p4，3648）对应 LISA 开发案例，而非 NAS：

|预算|模型/作业数|Hours|云费 USD|电费 USD|
|---|---:|---:|---:|---:|
|单模型|1|120|52–175|5|
|单次调参（作者估计需要 24 jobs）|24|2880|1238–4205|118|
|整个 R&D|4789|239942|103k–350k|9870|

p4 §4.2 的日志事实为项目跨度 172 天、123 次小型网格搜索、4789 个作业、作业 3 分钟至 9 天，使用 Titan X（72%）和 M40（28%）。3 分钟作业被作者解释为崩溃。日志汇总时间与表列美元估计应分开：脚注 8 用 P100 云价近似，脚注 9 电价采用美国平均 0.12 USD/kWh；均不是实际支付账单。按其价格反推，5、118、9870 美元约为 41.67、983.33、82,250 kWh，但舍入价格、功率与设施开销口径不足以据此恢复精确电量或完整能耗模型。

表列累计 GPU h 除以 172×24 得平均约 **58.13 张 GPU**，与正文“about 60 GPUs”及 p5 的约 58 张相容；它不是项目持续了 239,942 个墙钟小时。24×120=2880 能重现调参行，但 4789×120=574680 h，远高于 R&D 行。完整开发含不同长度的实验和失败作业，不能用最终模型的 120 h 乘所有作业数。

保留两项未决检查：正文 9998 GPU 天 ×24 = **239952 h**，比表列多 10 h，可能与显示精度有关，不能当成精确等式；正文又称平均作业长 **52 h**，但表列 239942/4789 ≈ **50.10 h**，52×4789=249028 h。这不是普通的“平均值取整到最近小时”就能消除的差异。缺少逐作业日志和平均值定义，无法确定是否口径、汇总或转录问题。Table 1 的 pipeline 排放与 Table 4 不在同一张完整功率账本中，本文材料不足以独立重建其精确连接，不能自行编造 CPU/DRAM 或分摊参数。

**4. 给定本地训练数据应怎样用**

用户给定：8 卡的合计平均 IT 功率 1.51543 kW、时长 84 h，另有设施电表 201 kWh。以下输入是用户数据，未经本审计独立测量。

- 可直接计算 IT 能耗 **127.29612 kWh**。这是已经合计的功率，不能再乘 8；前提是平均功率覆盖完整 84 h 且确为所需 IT 范围。如果“8 卡合计”实际只有 GPU 遥测、未含 CPU/DRAM 和其他应计设备，则只能称 GPU 能耗，须补齐范围才能与论文公式对应。
- 条件性套用论文 PUE 1.58：设施能耗估计 **201.1278696 kWh**。再套用论文美国历史因子，得 **191.8759876 lb = 87.03348 kg CO₂e**。这是按论文假设的可比估计，不是已经确定的本地实际碳排。
- 设施电表 **201 kWh** 若覆盖同一训练时段、同一资源及应计设施开销，则可直接作为设施层的测量能耗，**不再乘 PUE**。若条件性使用论文因子，则为 **191.754 lb = 86.97815 kg CO₂e**。缺本地适用排放因子时，实际碳排仍未知。
- 两个设施能耗相差 **0.1278696 kWh，约 0.064%**；在完全对齐边界的前提下，电表/IT 能耗之比约 **1.5789955**。这可作为该窗口的有效 PUE 比值，不证明机房长期 PUE 为 1.58。电表显示精度、时间对齐、共享负载和误差均未给出，接近也不能证明两组数据独立、校准正确或碳排准确。

两种能耗描述不相加，也不将一个当另一个的额外开销。设施电表若覆盖整个共享机房，201 kWh 就是机房读数，不能全部归给本作业。可在声明假设后做共享归因，例如对 CPU、DRAM、GPU 各自积分 `P_component(t)×allocation_component(t)`，再加入适用设施开销；利用率归因是分配模型，不是该作业独立电表测量，各分项未必共用一个利用率。须避免多个进程各自认领同一整机总功率造成双计，且不能从给定数编造分摊比例。

**5. 对引用和后续测量的建议与证据边界**

引用时同时保留模型/搜索预算、设备换算、估计性质、lb→kg 和 PUE/排放因子的出处。可以引用 Table 3 的数量级及 Table 4 展示的开发预算放大现象；不能把算术重现包装成实验准确性验证。所有结果仅涵盖方法计入的运行用电与相关设施开销，未见硬件制造、运输、报废等隐含碳排的完整生命周期核算，也未足以证明网络、存储等其他设备已全部覆盖。

后续测量应保存带时间戳的原始功率/电量、采样间隔与缺失点处理、设备与主机拓扑、CPU/DRAM/GPU 覆盖范围、作业起止与失败/提前停止记录、计量校准和电表边界。分别报告单次训练、调参和整个 R&D；并行时记录墙钟时长与累计设备小时。核对本地 201 kWh 的电表位置、时间窗、是否含别的作业及冷却，再决定是直接采用设施能量还是从 IT 能量乘实测 PUE。需要排放时补充适用地点、时间和生产/消费或合同核算口径的因子；如使用分时因子，应计算 Σ(Eᵢ×Iᵢ)，而非用任意平均强度乘总电量。

为解释论文剩余差异，具体应索取 §2 的功率时间序列、DRAM 采样与聚合方案、从 Titan X/1080 Ti 到 P100/V100 的转换依据、Table 3 未舍入计算表和 NAS 硬件速度换算；为 Table 4 索取逐作业日志、累计 GPU 时间定义、52 h 平均值算法及电费/排放账本。以上均未取得，报告没有将缺失内容当成事实。
